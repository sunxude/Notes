声明一个数组的时候，编译器会为其保留内存空间，然后再创建数组名。声明一个[[指针]]变量时，编译器只为指针本身保留内存空间。
数组名就是指向数组第一个元素的指针
多维数组的元素存储顺序是按照最右边的下标率先变化的原则，称为行主序。
对于多维数组在函数参数的使用
```C
一维数组
int x[10];
void fun1(int x[]);
void fun1(int *x);

二维
int x[3][4];
void fun2(int x[][4]);
void fun2(int (*x)[]);

```
把函数写成下面这样的原型是不正确的
```C
void fun2(int **x);
```
这个例子把x声明为一个指向整型指针的指针，他和指向整型数组的指针不是一回事 。
在多维数组初始化的时候花括号更大的作用是显示数组结构，而且对于不完整初始化列表没有花括号只能一个一个的打0了。
只有一维数组才能缺省提醒其他的都不能。

#### 指针数组
```C
int *x[10];
下标的优先级比*高，这个表示数组里有10个指向整型的指针。
```
sizeof返回的是整个数组所占用的字节而不是一个指针所占用的字节。单目运算符&返回一个指向数组的指针，而不是一个指向数组第一个元素的指针的指针。
