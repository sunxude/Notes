C通过运行时[[堆栈]]支持递归函数的实现。递归函数就是直接或间接调用自身的函数。
- 递：程序不断深入地调用自身，通常传入更小或更简化的参数，直到达到“终止条件”。
- 归：触发“终止条件”后，程序从最深层的递归函数开始逐层返回，汇聚每一层的结果。
- *递归*  是“自上而下”的解决问题而[[迭代]]是“自下而上”的解决问题。
- 在写递归代码时不必纠结于他的过程，而是相信他能顺利完成任务（限制条件设置正确）。
```C
/*该代码是描述递归和迭代是怎样进行的 */

#include <stdio.h>

void main()

{

    unsigned int number = 4267;

    binary_to_ascii(number);

}

void binary_to_ascii(unsigned int value)

{

    unsigned int quotient;

  

    quotient = value / 10;

    if(quotient != 0)

        binary_to_ascii(quotient);

    putchar((value % 10) + '0');

  

}

/*尾递归的方式计算n的阶乘*/

long factorial(int n)

{

    if(n <=1)

        return 1;

    else

        return n * factorial(n - 1);

}

/*迭代的方式计算n的阶乘*/

long factorial_iter(int n)

{

    long result = 1;

    for(int i = 2; i <= n; i++)

        result *= i;

    return result;

}
```
在使用递归之前先考虑这个函数的实现好处是否大于代价，递归产生的额外开销非常恐怖。
